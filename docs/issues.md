## 범위·착수 기준

현재 34개 Must(P0 25개/P1 6개/P2 3개)와 2개 제외 ID를 구분한다. 현재 축소 구현 목표는 2026-10-14이며 기존 10-16 전체 흐름 배포 기준과 담당별 일정을 자동으로 같은 의미로 취급하지 않는다. 26개 이슈는 공통 기반·결정·검증도 포함한다. ISS-001은 사용자 직접 요청에 따라 로컬 DB 설정으로 변경했고 compose.yaml을 작성했다. 애플리케이션 구현·실제 이슈 등록·DB 실행 검증은 하지 않았으며 담당자·시간 추정은 미배정이다.

ISS-001은 Neon 연결 전 사용할 로컬 DB 기반 작업이다. 미정 정책 확인은 ISS-002로 이동했다. ISS-002/003의 결정은 영향을 받는 개별 기능의 완료 조건이며 관련 없는 개발의 일괄 선행 조건이 아니다. 공통 기반 후 스터디·습관·집중을 병행하고 DB도 단계적으로 적용한다. 반응형은 각 화면 작업에 포함하며 ISS-025는 먼저 착수한다. ISS-020은 이번 범위에서 제외하고 번호는 보존한다. 최종 인수 ISS-026은 나머지 Must 기능의 완료를 기다린다.
