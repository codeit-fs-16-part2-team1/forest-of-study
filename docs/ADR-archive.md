## ADR-042 — 15초 연결 확인과 만료 시 자동 일시정지

- 날짜: 2026-10-10
- 상태: 대체: ADR-052
- 결정: 15초마다 연결을 확인하고 만료 시 마지막 확인 시각까지의 경과만 인정해 PAUSED로 복구한다. 후속 요청에서 만료를 검사하며 자동 재개·주기 상태 변경 작업은 제외한다. 다른 브라우저의 연장·조작은 차단한다. 자동 정지에는 포인트를 지급하지 않는다.
- 이유: 브라우저 종료 요청 누락을 연결 확인으로 보완하려 했다.
- 다시 볼 때: 연결 기반 자동 정지와 네트워크 오차를 처리할 때.

## ADR-043 — 일반 인증 토큰·한국 자정 만료와 타이머 키 분리

- 날짜: 2026-10-10
- 상태: 대체: ADR-051·ADR-052
- 결정: 자정 만료 일반 토큰과 별도 타이머 키를 LocalStorage에 보관한다. 일반 토큰은 HMAC-SHA256 서명, 타이머 키는 32바이트 난수 원문·DB SHA-256 해시로 관리하며 복구 시 교체하고 종료 시 폐기한다. 자정 후에도 기존 타이머 조작은 허용하고 삭제는 비밀번호로 재확인한다.
- 이유: 인증 만료와 진행 중인 집중의 조작 수명을 분리하려 했다.
- 다시 볼 때: 장기 인증·타이머 키·키 복구를 함께 도입할 때.

- 다시 볼 때: 원장 기반 정산과 종료 이력 구조가 필요할 때.

## ADR-047 — 90초 연결 만료·새로고침 유지·여러 탭 인계

- 날짜: 2026-10-10
- 상태: 대체: ADR-052
- 결정: 15초 연결 확인·90초 만료를 적용하고 만료 후 수동 재개한다. 종료 이벤트의 pause는 사용하지 않는다. 같은 브라우저의 담당 탭만 확인하며 다른 탭이 인계하고 중복 경과·지급은 막는다. 별도 탭 테이블은 추가하지 않고 다른 브라우저 조작은 차단한다.
- 이유: 일시적 연결 누락을 허용하면서 여러 탭의 집중을 유지하려 했다.
- 다시 볼 때: Heartbeat와 탭 인계를 다시 도입할 때.

## ADR-065 — Header·모달·시간 입력·기록표 색상·화면 상태

- 날짜: 2026-10-15
- 상태: 부분 대체: ADR-070·ADR-074
- 결정: 대체된 부분: 모든 모달은 배경·나가기·취소로 닫고 URL을 유지하며 Escape는 무시한다.
- 이유: 모달 닫기 동작을 기능별로 통일하려 했다.
- 다시 볼 때: 비밀번호 모달도 URL을 유지하는 방식으로 바꿀 때.

- ADR-074로 대체된 색상 결정: 모든 행을 현재 표시 순서의 index % 18로 배정하고 DB 색상 컬럼을 추가하지 않는다. 18색 값은 수신 대기로 둔다.
- 당시 이유: 별도 저장 없이 순서에 따라 18행을 넘는 기록도 표시하려 했다.
- 후속 결정: 기존 null 습관만 순서 표시를 유지하고 신규 습관은 기존 발자국 18종 중 필수 선택해 저장한다.

## ADR-060 — 현재 코드 기준 주간 기록 계약

- 상태: 부분 대체: ADR-074
- 대체된 결정: 주간 응답의 습관 행을 {id,name,cells:[{recordDate,completed}]}로 제공한다.
- 이유: 파생 가능한 중복 정보를 줄이려 했다.
- 후속 결정: 같은 행에 현재 Routine의 stickerColor를 추가해 과거 기록에도 선택 색상을 반영한다. 나머지 날짜·기간·정렬·셀 규칙은 유지한다.

## ADR-075 — 사용자 지정 배경의 공통 글자색

- 날짜: 2026-10-21
- 상태: 대체: ADR-079 (2026-10-22 기록)
- 배경: 사용자 지정 배경의 색상 선택 옆에 닉네임·스터디 이름·소개를 함께 바꾸는 글자색 선택을 추가한다.
- 결정:

  - 생성·수정 화면에서 custom 배경일 때만 글자색 하나를 지정할 수 있다. 기본값은 자동 대비이며 기본 글자색 사용을 선택하면 자동 대비로 돌아간다.
  - 선택한 글자색은 카드의 닉네임·스터디 이름·소개에 함께 적용한다. 직접 선택한 글자색은 진행 일수·포인트·응원 배지에는 적용하지 않는다.
  - 기존 배경으로 전환하면 직접 지정한 글자색을 비운다. textColor의 입력·응답·PATCH 기준은 API.md, 저장 제약·migration은 DB.md를 따른다.
  - ADR-076의 자동 대비를 기본값으로 유지하면서 세 텍스트 필드의 직접 지정을 추가한다.

- 이유: 배경과 함께 텍스트 색상을 직접 지정할 수 있게 하려 했다.
- 다시 볼 때: 글자색 직접 선택을 재도입할 때.
